    Por que isso importa
    
      
    
    
    

    
    
      
    Maiores valores declarados
    
      
    
      
    
      
      
      
      O valor inclui impulsionamento sem plataforma citada na nota; o confirmado é o piso. Esta é uma lista de valores declarados, não de irregularidades. Para conferir a prestação de contas, abra o portal de consulta do TSE e busque pelo nome.
      
    
      

    
      
      
      Cards para compartilhar
      
      
      Cinco cards no formato de story (1080×1920), com os números do recorte escolhido. Os mesmos números estão no resumo acima.
      
      
      
        
      
      
      
      
      
      
    
      
  
      

  
      
    
      Como medimos
      
    
      Lemos as despesas contratadas das campanhas nos dados abertos do TSE e separamos o gasto com anúncios em três níveis:
      
    
        
      
      1. Confirmado: o fornecedor ou a descrição nomeia a plataforma (Facebook, Instagram, Google, YouTube, X, TikTok). É o piso: o valor mínimo que sabemos.
        2. 
      
      2. Impulsionamento sem plataforma citada: a despesa é de impulsionamento, mas a nota não diz onde o anúncio rodou.
        3. 
      
      3. Provável: indícios, mas sem certeza. Nunca entra no número principal.
        4. 
    
      
    
      O número principal é o confirmado mais o impulsionamento sem plataforma citada. Os tetos (5%, 10%, 20%) contam só campanhas com pelo menos R$ 50.000 de despesas contratadas, para que campanhas minúsculas não inflem a conta. Os dados são parciais e mudam a cada prestação de contas; a classificação só foi conferida à mão no Rio Grande do Norte, então trate os números dos demais estados como estimativas.
